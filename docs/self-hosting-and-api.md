# 不使用项目方云服务的运行说明

公开仓库没有项目方的云端凭据。下载源码后，你可以完全使用 APK 内置资源，并把视觉识别请求发送到自己的服务商或自己的兼容接口。

## 运行模式

应用启动时只读取 APK 内的 `app/src/main/assets/`，不会请求远程资源清单。相机图片保存在应用私有目录。AI 识别是可选网络能力：没有配置 API Key 时，图鉴和本地功能仍可用，识别按钮会提示先完成配置。

## 使用第三方视觉 AI

在应用设置中配置以下字段：

| 字段 | 说明 |
| --- | --- |
| Provider | 选择服务商，或选择自定义接口 |
| API Key | 只在设备上填写，不提交到 Git |
| Model ID | 服务商提供的视觉模型 ID |
| Protocol | `Responses`、`Chat Completions` 或 `Anthropic Messages` |
| API URL | 完整 HTTPS 请求地址 |
| Auth Header | 通常是 `Authorization`，Anthropic 常用 `x-api-key` |
| Auth Scheme | 通常是 `Bearer`；没有 scheme 时留空 |
| Extra headers/body | 按服务商要求填写合法 JSON |

应用会把压缩后的 JPEG 作为图片内容发送，并要求模型返回一个唯一的标准宝可梦名称和异色判断。模型必须支持图片输入；普通文本模型会返回不支持视觉输入的错误。

## 自建兼容接口

推荐在自己的后端保存密钥，让 Android 客户端只调用自己的 HTTPS 网关。网关可以把请求转换成任意供应商协议，并执行：

1. 身份认证、速率限制和请求大小限制。
2. 图片 MIME 类型和最大边长校验。
3. 将请求转发到你的视觉模型供应商。
4. 把结果转换回应用选择的协议，并保持 JSON 字段结构兼容。
5. 记录请求 ID 和错误类别，但不要记录 API Key 或原始图片。

不要把供应商密钥写入 `gradle.properties`、源码、资源文件或 GitHub Actions 日志。部署新密钥后立即撤销旧密钥；客户端丢失时也应在供应商控制台轮换密钥。

## 本地资源

核心图鉴、详情 JSON、图片、小游戏素材和音效已经在 APK 的 assets 中。无需配置对象存储、CloudBase 或其他资源域名。更新资源时，在本地替换 `app/src/main/assets/` 内容并重新构建 APK。

## 本地语音包导入

额外语音包使用本地 manifest 和 ZIP。当前公开版保留本地语音文件存储和校验模型，但不包含远程下载或文件选择导入界面；需要该能力时，请在自己的分支实现文件选择器和导入流程。manifest 必须声明 `voiceId`、版本、ZIP SHA-256，以及每个 `.aac` 文件的大小和 SHA-256。ZIP 内的路径必须是相对路径，不能包含 `..` 或绝对路径。导入前请在可信环境生成并校验哈希；不要使用来路不明的音频包。

公开版本不会向项目方请求兑换码、授权或下载地址。若你要做团队内部的下载服务，请在自己的后端实现授权并把服务地址作为本地配置注入，不要恢复项目方的域名或凭据。

## 验证清单

- 断开网络后仍能打开图鉴、详情、收藏和小游戏。
- 设置为空时，应用不会自动发送图片。
- 使用你自己的 endpoint 和测试 Key 连接测试成功。
- `git grep` 不应出现 API Key、JWT、Bearer Token、私有域名或个人环境 ID。
